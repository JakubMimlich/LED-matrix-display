# LED_Matrix_Display

Jednoduchý modul displeja multiplexovaný na shift registroch 74HC595, použiteľného pre rôzne platformy s toleranicou 3,3V / 5V riadiacej logiky.

# Pripojenie

+V -> 5V 

SR -> D5

R -> D6

DT -> D7

GND -> G
